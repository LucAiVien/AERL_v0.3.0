# Notice

Automousera Research v0.3.0 is an independent skill implementation inspired by the empirical-search ideas described in Google Research's ERA (Empirical Research Assistant) work and its public reference implementation.

No Google source file is vendored in this package. `scripts/era_engine.py` is an independent implementation of an ERA-style Flat UCB/PUCT search interface. The v0.3 multi-agent orchestration, critic loop, blackboard, research budget, verification, ablation, and reporting layers are package-specific extensions.

See the bundled Apache-2.0 LICENSE for this package.
